# n8n_desafio
Assistente de Investimentos desenvolvido no desafio DIO, utilizando Python, BeautifulSoup, n8n, Webhooks, JavaScript e Google Gemini. A automação extrai dados de clientes, cruza perfis e saldos com investimentos disponíveis, gera mensagens personalizadas com IA e integra o envio de e-mails pelo Gmail.
